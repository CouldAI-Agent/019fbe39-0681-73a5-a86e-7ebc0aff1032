# Medical Treatment Service App

A modern medical treatment service app built with Flutter.

## Features
- Search for doctors, clinics, and medicines
- Browse medical categories (Cardiology, Ophthalmology, Neurology, Dental)
- View top rated doctors

## Tech Stack
- Flutter
- Material 3 Design

## Setup
1. Run `flutter pub get`
2. Run `flutter run`
